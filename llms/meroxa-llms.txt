# Meroxa

> Meroxa is a low-code, real-time data streaming platform. Its Conduit Platform
> moves data at scale between databases, SaaS applications and streaming systems
> using change data capture (CDC), pre-built connectors and a code-free
> dashboard. Developers build event-driven data applications with the Turbine
> framework (JavaScript, Python, Ruby, Go) and operate them with the `meroxa`
> CLI. Deployment modes: Meroxa-managed, self-hosted, and air-gapped.

## Notes

- No consumer-facing public REST OpenAPI is currently published; the legacy
  api.meroxa.io REST host no longer resolves. The platform is driven via the
  dashboard, the `meroxa` CLI, and Turbine SDKs.
- Connector plugins communicate over a gRPC interface and may be written in any
  language conforming to the Conduit SDK.
